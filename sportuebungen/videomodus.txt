# Aufnahmen testen (Knopf im Hauptmenue, nur beim Start mit "python Hauptprogramm.py --entwickler";
# in der Krankenhaus-Version fehlt er, dort gibt es die Videos nicht): Die App spielt alle hier eingetragenen Aufnahmen
# nacheinander statt der Webcam ab und zaehlt die Wiederholungen. "Uebungen waehlen" bleibt
# immer live, diese Datei aendert daran nichts.
#
# Eine Aufnahme pro Zeile (Pfad relativ zu sportuebungen/), Zeilen mit # werden uebersprungen.
# Jede Aufnahme laeuft mit ihrer eigenen Uebung: aus der summary.json neben dem Video, sonst aus
# dem Ordnernamen. Daher nur Aufnahmen von tools/record_exercise.py:
#   recordings/<uebung>/rec<N>/video.mp4
#
# Es wird nur gezaehlt: kein Ziel aus dem OP-Tag, keine Einfuehrung, keine Sprachausgabe. Jedes
# Bild wird der Reihe nach ausgewertet, so schnell der Rechner kann. Am Ende zeigt eine Liste pro Aufnahme die gezaehlten
# Wiederholungen und zum Vergleich die Anzahl laut Aufnahme (expected_reps in summary.json).
